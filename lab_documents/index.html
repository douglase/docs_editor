Lab Documents

These documents live in a private GitHub repository. Sign in with the GitHub account that has access to it; the pages are fetched straight from GitHub into your browser.

Create a fine-grained token (github.com → Settings → Developer settings → Fine-grained tokens): under Repository access choose "Only select repositories" and pick lab_documents; under Repository permissions set Contents to Read-only. To edit as well, set Contents and Pull requests to Read and write, and Issues to Read-only. Copy the github_pat_… value here.
