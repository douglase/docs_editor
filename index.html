UASAL document editors

Browser editors (Sveltia CMS) for Markdown kept in GitHub. Each one edits a single repository through your own GitHub login; nothing is stored on this site.

  • lab_documents — lab policies, onboarding, safety and computing guides (uasal/lab_documents). Rendered site: internal docs server (campus/VPN).

To add a repository: copy _template/ to a new folder named after the repo, edit its config.yml, and add a line above. See the README.
