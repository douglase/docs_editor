Documents

Readers and editors for Markdown documentation kept in private GitHub repositories. Each one fetches its repository straight into your browser with your own GitHub login; nothing is stored on this site.

  • lab_documents — lab policies, onboarding, safety and computing guides (uasal/lab_documents). Editor.

To add a repository: copy _template/ to a new folder named after the repo, edit its config.yml, and add a line above. See the README.
